## `🌊 research_control_room`

### Underwater object detection under domain shift

> An active research collaboration around pool-to-sea transfer for underwater
> debris and PPE detection, working with **LABUST / University of Zagreb FER**.

The practical question is simple: **how little local annotation can a detector
use and still generalize reliably to a new underwater site?**

```text
UNDERWATER-DETECTION/
│
├── public sea-domain base
│   ├── TrashCan + SeaClear
│   └── 12,953 train / 2,869 validation images
│
├── corrected outdoor benchmark
│   ├── deduplicated by source frame
│   ├── split by complete video — no sequence leakage
│   └── held-out cross-platform camera test
│
├── reproducibility
│   ├── deterministic dataset builds
│   ├── provenance + environment ledgers
│   └── per-class and per-domain evaluation
│
└── live status
    ├── public build verified
    ├── real Colab T4 timing complete
    └── full 100-epoch baseline queued
```
